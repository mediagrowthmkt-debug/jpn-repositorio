# JPN Hardwood Floors, assinatura de e-mail

Repositório público para hospedar a assinatura de e-mail da JPN Hardwood Floors.

Arquivos principais:

- `index.html`: página com instruções para abrir e copiar a assinatura.
- `assinatura.html`: assinatura renderizada para copiar e colar no Gmail.
- `assinatura-original.html`: cópia do HTML final aprovado antes da troca da URL pública da logo.
- `email/logo-jpn-hardwood-floors.png`: logo pública usada pela assinatura.
